## 1. Comprehension: what we're building and why

Today only admins can manage games, questions, rosters and reports. Hosts can only create and run rooms. Games also don't belong to a course. A game only gets a course when someone opens a room for it. Which host can run which game is decided by per-user `UserGameAccess` grants.

T4 changes this in five ways:

- **Games belong to a course.** `games.course_id` is a nullable column, filled in by a migration from past completed sessions. You only see a game if you hold `HOST` on its course.
- **Grants become an opt-in narrowing.** A new `restricted` flag means the course's hosts *also* need a grant to use the game
