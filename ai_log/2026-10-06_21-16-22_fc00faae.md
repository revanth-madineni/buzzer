## AI Summary

A **Core delete** sends one SQL `DELETE` statement straight to the database. An **ORM delete** asks SQLAlchemy to delete a Python object, and SQLAlchemy decides what SQL to run.

SQLAlchemy has two layers:

- **ORM** (Object Relational Mapper): you work with Python objects like `course`, and SQLAlchemy turns your changes into SQL.
- **Core**: you build SQL statements in Python yourself, and SQLAlchemy runs them as written.
